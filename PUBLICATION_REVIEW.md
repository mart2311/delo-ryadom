# Проверка перед публикацией

Подготовлена отдельная копия текущих исходников без переноса старого репозитория и его истории.

- `.env` и его значения не перенесены; опубликованы только `.env.example`.
- Встроенные пароли базы и Django-ключ заменены обязательными переменными окружения.
- Фиксированные пароли демонстрационных пользователей удалены. Наполнение базы запускается вручную с `DEMO_PASSWORD`.
- Демо-почта заменена на `example.com`, телефоны удалены, адреса заказов обезличены.
- Примерные контакты и реквизиты обозначены как демонстрационные.
- Не включены `.idea`, кэши Python, зависимости, базы, дампы и пользовательские загрузки; добавлены `.gitignore` и `.dockerignore`.
- Порты Docker привязаны к localhost для локальной демонстрации.
- README описывает функции, стек, запуск и известные ограничения прототипа.

Проверка предназначена для предотвращения публикации локальных данных и очевидных секретов. Она не заменяет аудит безопасности приложения. Не используйте демонстрационное окружение с реальными персональными данными.

## Выполненные проверки

- Production-сборка React/Vite прошла.
- `django check`: ошибок нет; расхождений моделей и миграций нет.
- Миграции и загрузка синтетических демо-данных прошли в изолированной SQLite-базе в памяти.
- Docker Compose прошёл проверку конфигурации. Полный запуск с PostgreSQL не проверялся: Docker Engine на машине не запущен.
- Проверен фактический список 91 публикуемого файла: значений `SECRET_KEY` и `POSTGRES_PASSWORD` из исходного `.env`, распространённых форматов ключей и исключённых локальных артефактов не найдено.
